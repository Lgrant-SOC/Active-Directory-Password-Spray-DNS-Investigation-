# Active Directory & Wazuh Security Investigations

Hands-on cybersecurity lab projects focused on **Active Directory, Windows security events, authentication attacks, Wazuh detection, and endpoint monitoring**.

## Projects

### Project 01 — Active Directory Password Spray & Wazuh Investigation

Investigated failed authentication activity against a Windows Server environment and analyzed Windows Event ID 4625 using Wazuh.

### Project 02 — Wazuh Brute-Force Detection Using a Custom Rule

Created and tested a custom Wazuh detection rule to identify repeated failed authentication attempts.

### Project 03 — Sysmon Process Monitoring & Wazuh Detection

Used Sysmon process telemetry with Wazuh to investigate endpoint activity and security events.

### Project 04 — Wazuh File Integrity Monitoring & Canary File Detection

Configured file integrity monitoring and investigated changes to a monitored canary file.
